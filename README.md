# Каталог вагонов

Справочник по грузовым вагонам: характеристики, тележки и запчасти, сроки
ремонта, сертификаты, допустимые грузы (поиск по 1 870 видам груза),
вагоностроительные заводы и ремонтные депо. Собран из внутренней
Excel-выгрузки, чтобы сотрудникам не приходилось искать всё это вручную по
справочникам.

Сайт статический — весь код в [`docs/`](docs/), данные читаются из
[`docs/data/catalog_data.json`](docs/data/catalog_data.json) через
`fetch()`. Обновление раз в год (или чаще, пока идёт наполнение) не требует
сервера — только пересборку и коммит.

## Структура

```
RZD.md               исходная выгрузка из Excel (первоисточник)
db/
  schema.sql          DDL — 44 таблицы SQLite
  build_db.py          RZD.md -> rzd.db
  export_catalog.py    rzd.db -> docs/data/catalog_data.json
  rzd.db               собранная база (пересоздаётся build_db.py)
docs/
  index.html            сама страница (HTML+CSS+JS, без сборки)
  data/catalog_data.json  выгрузка для сайта (генерируется export_catalog.py)
```

## Как обновить данные

1. Поправить `RZD.md` (или сразу `rzd.db`, если правки точечные)
2. Пересобрать базу и выгрузку:
   ```bash
   cd db
   python build_db.py        # RZD.md -> rzd.db
   python export_catalog.py  # rzd.db -> ../docs/data/catalog_data.json
   ```
3. Проверить локально:
   ```bash
   cd ../docs
   python -m http.server 8000
   # открыть http://localhost:8000
   ```
4. Закоммитить и запушить — GitHub Pages обновится сам за пару минут

## Локальный запуск

Открывать `docs/index.html` напрямую (`file://`) не получится — браузер
блокирует `fetch()` для локальных файлов. Нужен любой веб-сервер:

```bash
cd docs
python -m http.server 8000
```

## Аналитика

В `docs/index.html` в `<head>` оставлено место под счётчик посещений (искать
комментарий «Аналитика»). Сайт статический — свой сервер для сбора
статистики не нужен, подключается сторонний счётчик. Варианты:

- **Яндекс.Метрика** — бесплатно, без ограничений, привычный интерфейс.
  Требует создать аккаунт на metrika.yandex.ru и вставить выданный код
  счётчика вместо комментария.
- **GoatCounter** — бесплатно, open-source, минималистичная статистика без
  профилирования пользователей.
- **Plausible** — приятный интерфейс, но бесплатно только self-hosted
  (нужен свой сервер) или платная подписка на облачную версию.

Заводить аккаунт нужно самостоятельно — это единственный шаг, который
нельзя сделать за вас.

## Ограничения текущих данных

Три таблицы в базе созданы, но пока пусты в источнике: услуги депо,
контакты депо. Прямая авторизация депо на ремонт конкретной модели указана
только для части вагонов — для остальных сайт показывает депо,
компетентные по типу/роду вагона (более широкий, но честный список).
